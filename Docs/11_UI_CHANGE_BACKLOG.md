# LootUp UI 변경 및 리뉴얼 백로그

작성일: 2026-10-20
상태: 기능 개발 중 누적, 일괄 리뉴얼 대기

## 1. 운영 원칙

- 기능 구현 중에는 기능 동작에 필수적인 최소 UI만 추가한다.
- 시각 디자인, 배치 통일, 가독성 개선은 이 문서에 누적하고 개별 기능 작업에서 산발적으로 수정하지 않는다.
- 각 기능 작업 완료 보고에 `UI 영향: 없음/변경/신규`를 기록한다.
- UI 항목은 기능 ID, 대상 화면, 필요한 상태, 우선순위와 검증 기준을 함께 남긴다.
- 2026-11-29 기능 UI 범위를 동결한 뒤 2026-11-30~12-06에 일괄 리뉴얼 후보 작업으로 묶는다.
- 일괄 리뉴얼 예상 작업량은 범위 동결 시 산정하며, 승인 전까지 출시 104시간 진척에는 포함하지 않는다.

### 2.1 캐릭터 구매 UI 처리 경계

- `SHOP` 기능 개발에서 독립 구매 버튼, 캐릭터명·가격·현재/구매 후 잔액 확인창, 처리 중 상태, 잔액 부족·오프라인·서버 실패 안내와 구매 성공 피드백을 구현한다.
- Landy GameMoney와 Ninja Ruby 구매·재로그인·중복 차감 검증은 위 최소 구매 UI가 준비된 뒤 완료 판정한다.
- Alice 광고 `0/5` 진행도와 시청 버튼은 광고 SDK·서버 누적 진척도 구현과 함께 처리한다.
- 11월 30일~12월 6일 일괄 UI 리뉴얼에서는 START/UNLOCK 색상·아이콘, 레이아웃, 역할 배지와 능력치 비교 등 시각 품질을 다듬는다.
- 현재 `LobbyController`의 START 버튼 재사용 방식은 임시 연결로 간주하며 출시 완료 UI로 판정하지 않는다.

## 4. 일정 반영

| 기간 | 작업 | 완료 기준 |
|---|---|---|
| 기능 개발 기간~11/29 | UI 변경·신규 요구사항 누적 | 기능별 상태와 검증 기준 기록 |
| 11/23~11/29 | UI 범위·작업량 동결 | 필수/출시 후 항목 분리, 예상 시간 확정 |
| 11/30~12/06 | 일괄 UI 리뉴얼 후보 | 승인된 필수 화면 디자인과 상태 통일 |
| 12/07~12/20 | 실기기 UI 회귀 검증 | Safe Area, 가독성, 입력 중복과 오류 상태 확인 |

UI 리뉴얼이 12월 6일 기능 동결을 위협하면 필수 상태 표시와 구매 안전성만 출시 범위에 포함하고, 전면 시각 리뉴얼은 출시 후로 전환한다.
