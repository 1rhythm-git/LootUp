# XP V0.2 통합 성장 분석

## 1. 검증 조건

- 캐릭터: Agent X, Alice, Landy, Ninja
- 시작: Lv.1 / XP 0
- 목표: Lv.20
- 표본: 캐릭터당 300명 x 200회, 총 240,000런
- 일일 플레이: 3회
- Seed: 20261020

## 2. 무결성

- 캐릭터별 원본 60,000행, 총 240,000행을 확인했다.
- `(Sample, Run)` 중복은 0건이다.
- 이전 런의 `EndLevel/EndXP`와 다음 런의 `StartLevel/StartXP` 승계 오류는 0건이다.
- 통합 CSV의 P50 목표 도달 런, 최종 P50 레벨, P50·P90 층을 원본에서 재계산했으며 불일치는 0건이다.
- 설정 JSON 4개와 SVG 5개의 파싱을 통과했다.

## 3. 성장 결과

| 캐릭터 | Lv.20 P50 | 예상 일수 | 최종 P50 레벨 | P50 층 | P90 층 |
|---|---:|---:|---:|---:|---:|
| Agent X | 171회 | 57.0일 | 21 | 18F | 25F |
| Landy | 165회 | 55.0일 | 21 | 22F | 31F |
| Alice | 159회 | 53.0일 | 22 | 27F | 42F |
| Ninja | 154회 | 51.3일 | 22 | 35F | 59F |

모든 캐릭터가 200회 안에 Lv.20에 도달했다. P50 범위는 154~171회로 목표인 150~200회를 충족하며, 가장 빠른 Ninja와 가장 느린 Agent X의 차이는 17회로 약 11%다.

## 4. BM 해석

XP 성장 속도는 캐릭터별로 비슷하게 유지하면서 실제 런 성능은 차등화하는 구조가 적합하다. 강한 캐릭터를 해금하려는 게임머니·광고·Ruby 동기를 만들 수 있고, 구매한 캐릭터가 다시 더 빠르게 성장하는 복합 격차는 줄일 수 있다.

현재 P50 층은 Agent X 대비 Landy +22%, Alice +50%, Ninja +94%다. Landy는 해금 동기로 활용 가능한 범위에 가깝지만 Alice와 Ninja는 리더보드나 보상 효율에서 필수 캐릭터가 될 위험이 있다. 성능을 동일하게 만들 필요는 없지만 P50 기준 상위 캐릭터의 목표 우위를 약 +20~35% 범위에서 먼저 검토한다.

캐릭터별 역할 차이는 유지한다. 단순히 모든 기본 수치를 높이기보다 생존, Fever, 아이템 효율, 고점 기록처럼 서로 다른 강점을 배치한다. 경쟁 콘텐츠가 포함되면 캐릭터별 리더보드 또는 캐릭터 보정을 사용해 구매 여부가 순위를 직접 결정하지 않도록 한다.
