## 성장 속도 비교

| 캐릭터 | Lv.5 P50 | Lv.10 P50 | Lv.15 P50 | 200회 최종 P50 레벨 | Lv.20 P50 추정 |

Lv.20 추정은 각 표본의 마지막 20런 평균 XP가 계속된다는 단순 외삽이다. 실제 시뮬레이션 범위를 벗어나므로 확정값이 아니며, Ninja·Alice는 300회, Landy·Agent X는 450회 이상으로 재실행해야 직접 확인할 수 있다.

## 도달 층 비교

| 캐릭터 | 200회 P50 층 | 200회 P90 층 | 주요 종료 경향 |
|---|---:|---:|---|
| Ninja | 33F | 56F | HP 종료 약 37%, 시간 종료 약 63% |
| Alice | 26F | 40F | 시간 종료 약 89~90% |
| Landy | 21F | 30F | 시간 종료 약 97% |
| Agent X | 17F | 24F | 시간 종료 약 90~91% |

각 캐릭터는 레벨이 올라가도 P50 도달 층이 거의 변하지 않는다. 현재 XP 레벨은 기본 이동속도·HP 등을 성장시키지 않으며, 스킬 발동도 기록 성능을 뚜렷하게 바꾸지 못했다.

## 해석

1. 기본 이동 성능이 높은 캐릭터가 더 높은 층에 도달하고 더 많은 층·점수 XP를 받아 더 빠르게 레벨업한다.
2. 결과적으로 Ninja와 Agent X 사이 Lv.15 도달 시점은 P50 기준 61런 차이다. 동일한 필요 XP 테이블이라도 성능 차이가 성장 속도 차이로 다시 확대된다.
3. Agent X는 Lv.5, Alice·Landy는 Lv.15에 스킬을 해금하지만 해금 전후 P50 층 변화가 보이지 않는다.
4. Ninja 스킬은 Lv.20 해금인데 200회 안에 누구도 도달하지 못해 현재 테스트 범위에서는 발동되지 않는다.
5. 성장 체감을 CharacterCoin 강화에 맡길지, XP 레벨에도 소규모 성능 보정을 줄지 기획 결정을 먼저 내려야 한다.

## 권장 후속 순서

1. 현재 수치를 바로 수정하지 않고 실제 대표 런으로 캐릭터별 시간 종료 구간을 대조한다.
2. XP 레벨의 역할을 `스킬 해금 전용` 또는 `소규모 스탯 성장 포함` 중 하나로 확정한다.
3. 스킬 해금 목표 기간을 먼저 정하고 Lv.20 필요 XP를 조정한다.
4. 캐릭터별 성능으로 XP 격차가 확대되는 것이 의도인지 검토하고, 필요하면 런 기본 XP 비중을 높이고 층·점수 XP 비중을 낮춘다.
